Mon histoire

« Partir à l'étranger n'était pas qu'une case à cocher sur mon CV. »

En avril 2026, j'ai traversé l'Atlantique pour rejoindre Biotonix à Montréal. Une startup technologique canadienne spécialisée dans les solutions de santé connectées. Ce n'était pas juste un stage, c'était un pari sur moi-même. Sortir de ma zone de confort, travailler dans un environnement international, m'adapter à une nouvelle culture professionnelle... Chaque jour était un défi stimulant.

"Cette expérience m'a appris que les meilleures opportunités naissent quand on ose sortir de sa zone de confort. Le Canada ne m'a pas seulement offert un stage, il m'a offert une vision nouvelle de ce que je veux accomplir."

Missions et responsabilités

En tant que stagiaire développeur web et mobile, mes missions principales incluent :

  • Développement d'applications web modernes avec .NET Core et Angular
  • Création d'applications mobiles cross-platform avec Ionic
  • Conception et gestion de bases de données SQL Server
  • Utilisation d'Entity Framework pour l'accès aux données
  • Travail en méthodologie Agile avec Azure DevOps
  • Gestion du code source et collaboration via Git
  • Participation aux sprints de développement et aux réunions d'équipe
  • Tests et débogage des applications développées

Stack technique

Ce stage me permet de travailler avec des technologies modernes et recherchées sur le marché :

Backend
.NET Core pour le développement d'API REST robustes et performantes
Frontend Web
Angular pour la création d'interfaces web dynamiques et réactives
Mobile
Ionic pour le développement d'applications mobiles cross-platform (iOS et Android)
Base de données
SQL Server avec Entity Framework pour la gestion des données
Méthodologie & Outils
Agile, Azure DevOps pour la gestion de projet, Git pour le versionning
